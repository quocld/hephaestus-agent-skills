# Code of Conduct

Hephaestus Skills adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and constructive in issues, pull requests and reviews.
- Critique code and ideas, never people.
- No harassment, insults, discrimination, or publishing anyone's private information.

## Scope

This applies to every space of the project: the GitHub repository (issues, pull requests, discussions, reviews) and anyone representing the project elsewhere.

## Reporting

Report unacceptable behavior privately to the maintainer, [Ryan Le (@quocld)](https://github.com/quocld), through the contact on that GitHub profile.
Reports are handled confidentially.
The maintainer may remove comments, commits or other contributions that break this code, and may ban a contributor temporarily or permanently, following the enforcement guidelines of the Contributor Covenant.
