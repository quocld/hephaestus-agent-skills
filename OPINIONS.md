# OPINIONS.md

A compact map of my engineering and product viewpoints, written for LLM context.
Agents read this when a decision would benefit from knowing how I think.
Keep each section to a few sentences; replace the seed bullets below with my own views over time.

## Engineering

- Code is rarely the deepest bottleneck. The hard parts are deciding what is worth building and verifying that it works.
- Prefer simple, boring, maintainable solutions over clever ones. Simplify before adding machinery.
- End-to-end tests that mirror real users are the strongest proof a feature works.

## Working with agents

- AI is a tool; I stay accountable for every change it makes, so I review and approve what ships.
- Use independent review (fresh context, separate session) for changes where mistakes are costly.
- Keep durable state on disk (specs, AGENTS.md, handoff notes) rather than inside one session's memory.

## Product and UX

- Pixel-level polish matters. If it looks off, it is off.
